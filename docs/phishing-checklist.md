# Phishing Checklist

Use this checklist when a user reports a suspicious email.

## 1. Initial Review
- [ ] Confirm the ticket source and timestamp
- [ ] Identify the reported user and mailbox
- [ ] Capture the subject line and sender address
- [ ] Note whether attachments or links are present

## 2. User Impact
- [ ] Did the user open the email?
- [ ] Did the user click a link?
- [ ] Did the user open an attachment?
- [ ] Did the user enter credentials or other information?
- [ ] Did the user forward the email to anyone else?

## 3. Message Review
- [ ] Check the display name vs. actual sender address
- [ ] Look for spelling errors, urgency, or unusual requests
- [ ] Review any embedded links
- [ ] Review any attachments
- [ ] Check whether the request is unexpected for the user

## 4. Account Review
- [ ] Check for unusual recent logins
- [ ] Check for recent MFA prompts or password changes
- [ ] Look for related tickets or alerts
- [ ] Note whether the account appears locked or restricted

## 5. Decision
- [ ] Determine if this appears to be phishing, spam, or legitimate
- [ ] Determine whether the user clicked or submitted information
- [ ] Decide whether to document and close, monitor, or escalate
- [ ] Complete notes and handoff if needed
