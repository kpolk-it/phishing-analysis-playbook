# Phishing Decision Guide

## If the user did not click or submit information
- Document the report
- Capture sender, subject, and URL if present
- Confirm no related account alerts
- Usually lower urgency
- May still escalate if the campaign appears widespread

## If the user clicked a link but did not enter information
- Document the URL
- Check for unusual login or MFA activity
- Watch the account briefly if policy requires it
- Escalate if anything looks abnormal

## If the user entered credentials or downloaded an attachment
- Treat as higher priority
- Document exactly what the user submitted or opened
- Check recent logins, MFA events, and inbox rules if available
- Escalate quickly with a clear handoff

## Escalate When
- Credentials may have been entered
- An attachment was opened
- Multiple users received the same message
- The account already shows suspicious activity
- Policy requires security team review
