# Example: User Clicked the Link

**Scenario:** A user clicked a link in an email that appeared to come from payroll support.

### Triage Steps Performed
- Confirmed the user clicked the link
- Asked whether any information was entered
- Reviewed recent login and MFA activity
- Captured the URL and sender details

### Findings
- User clicked the link but said no information was entered
- Sender domain was not legitimate
- No successful unusual login was found during initial review
- Account was not locked

### Decision
Escalated for further review because the user clicked a suspicious link. Requested monitoring of the account and analysis of the URL.

### Documentation Notes
Included user statement, URL, timestamp, and current account status.
