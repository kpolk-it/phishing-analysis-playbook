# Example: User Did Not Click

**Scenario:** A user reports an email that appears to come from IT support and asks them to reset a password.

### Triage Steps Performed
- Reviewed sender address and subject line
- Checked the embedded link
- Confirmed the user did not click the link
- Reviewed the account for unusual recent activity

### Findings
- Sender used a lookalike domain
- Link pointed to an external site
- User did not click or enter information
- No unusual login activity was found

### Decision
Documented as a phishing attempt. No account compromise indicators were observed. Escalated for tracking of the malicious domain.

### Documentation Notes
Included sender address, subject, URL, and confirmation that the user did not interact with the message.
