# Phishing Analysis Playbook

A practical playbook for reviewing reported phishing emails, gathering key details, and deciding whether to close, monitor, or escalate.

This project is designed for Tier 1 SOC, security operations, and IT professionals moving into cybersecurity.

## Purpose

- Standardize phishing email review
- Improve documentation quality
- Help analysts decide next steps quickly
- Provide reusable templates and examples

## How This Relates to SOC Work

Phishing review is one of the most common Tier 1 SOC tasks. This playbook focuses on:

- Reviewing sender, subject, links, and user actions
- Collecting evidence without overcomplicating the first pass
- Deciding whether credentials may have been entered
- Creating a clean handoff for deeper investigation

## Contents

- Phishing checklist
- Email header review guide
- Decision guide (clicked vs. not clicked)
- Example write-ups
- Notes and handoff templates

## How to Use

1. Start with the [Phishing Checklist](docs/phishing-checklist.md)
2. Review headers using the [Header Review Guide](docs/header-review-guide.md)
3. Use the [Decision Guide](docs/decision-guide.md)
4. Document findings with the templates
